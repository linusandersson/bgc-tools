What's proportionate, by role and country

A quick reference for which checks fit which roles across the Nordics — and how access works in each market. Pick a country, then read a row.

How to read a cell

  • ●Standard — proportionate, routinely run for this role.
  • ◐Role-dependent — run only where the specific duties justify it.
  • ·Not proportionate — generally excessive for this role.
  • ×No legal basis — not available for this role in this market.

The model is the same everywhere: the candidate holds and presents their own record. Talentech orchestrates the request and shows status only — partners run the checks, and report content never lands on Talentech's systems.

Indicative proportionality guidance for sales conversations — not legal advice. Final check scope is agreed with each customer (and their counsel where needed).
